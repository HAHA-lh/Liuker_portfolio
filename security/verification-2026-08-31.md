## 待确认与边界

GitHub 仓库改为私有、历史预览/部署地址增加登录验证仍待站长确认，本轮没有
修改这些访问权限。公开仓库中现有内容仍可能被复制，已有副本也无法追回。

这些措施只能提高常见爬取、直链和盗链的门槛，不是 DRM。伪装完整浏览器请求、
真实浏览器抓取和录屏仍可能取得可观看内容。需要更强保护时，应另行实施私有
媒体存储、短期播放授权和水印；不要把隐藏下载按钮或 robots.txt 当作绝对保护。
